一、重复功能汇总与合并方案
================================================================================

1. 注册表 (Registry) 模式 — 3 处重复 → 已合并为 1 处
   - backend/app/llm/registry.py   (函数式 + 装饰器风格)
   - backend/app/runtime/registry.py (类式 classmethod 风格)
   - backend/app/model/registry.py  (函数式 + 装饰器风格)
   → 新建统一类: backend/app/core/registry.py (Registry[T], 泛型 + 装饰器/直接注册双模式)

2. 工厂 (Factory) 模式 — 2 处重复
   - backend/app/llm/factory.py   (LLMFactory)
   - backend/app/runtime/factory.py (已删除，功能合并到 ModelManager)
   → ModelManager 整合 LLM 与 Runtime 两种创建路径，runtime/factory.py 已不存在

3. load_dotenv() 重复调用 — 3 处
   - backend/app/__init__.py (第 7 行)
   - backend/app/config.py   (第 6 行)
   - backend/app/llm/__init__.py (第 9 行)

4. 路由目录重复
   - backend/app/routes/ (只有空 __init__.py)
   - backend/app/routers/ (含 system.py，实际使用)
   → 已删除 routes/

5. backend/app/model/ 目录 — 只剩 __pycache__、无源码
   → 已删除

6. backend/app/ai/providers/ — 只剩 __pycache__、无源码
   → 已删除

二、逻辑错误汇总与修复
================================================================================

错误 1: backend/app/llm/factory.py — get_provider 重复导入
  修复前: from .registry import get_provider
          from backend.app.llm.registry import get_provider  (重复！)
  修复后: 只保留 from backend.app.llm.registry import get_provider

错误 2: backend/app/llm/factory.py — 导入不存在的 .config 模块
  修复前: from .config import load_model_config
          (.config → backend/app/llm/config.py，该文件不存在)
  修复后: from backend.app.config import load_model_config

错误 3: backend/app/config.py — 缺失 import (Path, yaml)
  修复前: MODEL_CONFIG_PATH = Path(__file__).parent / "models.yaml"
          return yaml.safe_load(f)
          (Path 和 yaml 均未导入，运行时报 NameError)
  修复后: 添加 from pathlib import Path; import yaml

错误 4: backend/app/config.py — MODEL_CONFIG_PATH 指向错误
  修复前: Path(__file__).parent / "models.yaml"
          → backend/app/models.yaml (不存在)
  修复后: Path(__file__).resolve().parent.parent.parent / "config" / "models.yaml"
          → <项目根>/config/models.yaml (正确)

错误 5: backend/app/runtime/huggingface.py — 默认值为类型注解占位符
  修复前: model_name: str = "model_name: str"
          → 硬编码错误，会导致加载不存在的模型
  修复后: model_name: str = "Qwen/Qwen2.5-0.5B-Instruct"

错误 6: backend/app/runtime/base.py — 参数名不一致
  修复前: def generate(self, request: str, **kwargs)
  修复后: def generate(self, prompt: str, **kwargs)
          (与子类 HuggingFaceRuntime 和 DummyRuntime 保持一致)
