# Scripts

## 目录说明

`scripts/` 用于存放 GrayProject 的所有辅助工具脚本。

项目中的自动化操作统一放置于此，避免工具脚本散落在各个目录。

---

## 当前脚本

| 文件 | 功能 |
|------|------|
| setup.py | 初始化开发环境 |
| check_env.py | 检查开发环境 |
| start_backend.py | 启动后端服务 |
| start_frontend.py | 启动前端服务 |
| stop_all.py | 停止所有服务 |
| clean.py | 清理缓存和临时文件 |

## 开发规范

所有自动化工具统一放置在 `scripts/` 目录。

新增脚本时应：

1. 添加清晰的文件注释。
2. 保持单一职责。
3. 提供统一的命令行入口。
4. 更新本 README。
